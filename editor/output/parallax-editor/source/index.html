TVOJA SCENA, TVOJ RASPORED

Od asseta do beskonačne ulice.

  1. Dodaj. Klikni sliku u Biblioteci ili je povuci na platno. Novi element ide u aktivni sloj. Zaključan sloj prvo otključaj.
  2. Posloži. Povlači elemente, mijenjaj veličinu kutnim ručkama ili upiši točne brojeve. „Sloj” određuje redoslijed i parallax.
  3. Zatvori petlju. U kartici „Petlja” odredi početak i kraj. „Spoj petlje” prikazuje kraj i početak zajedno. Promjene na kopiji mijenjaju isti original.
  4. Provjeri vožnju. Pokreni ▶ i gledaj kako se slojevi kreću različitim brzinama. Kamera se ne resetira na spoju — sadržaj se ponavlja bez skoka.
  5. Predaj Hermesu. „Preuzmi projekt” sprema jedan JSON sa slikama, rasporedom, brzinama, granicama petlje i referentnim rendererom. Istu datoteku možeš kasnije otvoriti ovdje.

Automatska kopija sprema se u ovaj preglednik. Preuzeti JSON je prenosiva verzija i sigurnosna kopija.
